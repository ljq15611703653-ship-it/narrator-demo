# 第一轮设计说明

## 一句话规则

玩家选择现在，旁白固定过去；预言固定未来，但不固定玩家的行为。

## 言出法随

1. 玩家提交自然语言。
2. LLM只能在当前物件、工具、动作和可声明事实组成的封闭候选中返回一个ID或拒绝。
3. 规则引擎复核工具、距离、直接结果边界和既有固定事实。
4. 若仍有合法世界线，玩家要求的直接结果必定成立。
5. 旁白从支持该结果的合法过去中选一条，并把过去及其必然推论永久写入关系图。
6. 若玩家的要求已与所有世界线冲突，实际结果和失败过去仍会被固定；玩家既没得到目标，也失去更多后续声明空间。

毒性只能在拥有试纸时声明，因为此时玩家具有当场证明结果的手段。枪膛在扣扳机时可以直接压实，因为开火事件本身会揭示是否有弹；但“某人死亡”不是开火的直接结果，不能被一并声明。

## 预言

预言只描述客观事件，不描述主角想法或命令主角行为。LLM决定什么时候从当前房间的预写预言中说出哪一条，也可以等待；规则图独立判断完整句子是否兑现。到期前若玩家没有完成，旁白只能用同一套公开事件算子补足，不能绕过谓词。

## 七八层路线

第7层是当前所在的10个真实房间。第8层是12条完全不同的大故事线。进入第7室前，系统按已经发生的事件，以 `K → I → F → D → E → B → C → G → H → J → A → L` 的优先级压实一条路线，此后不可更改。

每个路线/房间组合拥有独立剧情节拍、见证者、缺失核心物、移位核心物、缺失碎片和专用现场操作，因此构成120个实际场景，而不是120个数值标签。完整内容在 `world-data.js` 的 `level8Arcs` 与 `routeScenes` 中。

## 第二周目遗产

章末保存故事线、结局、全部固定过去、已揭示属性、玩家抢先兑现的预言、120现场操作、携带物、改变过的物件状态与三类关系分数。下一轮不需要猜第一轮发生过什么，可以直接把该对象作为世界初始条件。
